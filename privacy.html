プライバシーポリシー

1. このアプリについて

「おもいで美術館」（以下「本アプリ」）は、思い出の品や作品を撮影し、バーチャルな美術館として閲覧するためのウェブアプリです。

2. 保存場所

撮影した写真・3Dファイル・タイトル・メモなどのデータは、利用者ご本人の Google ドライブ内の「おもいで美術館」フォルダにのみ保存されます。本アプリの提供者がこれらのデータを受け取ったり、閲覧・保管したりすることはありません。本アプリには、データを受け取るためのサーバーがありません。

3. Google アカウントで利用する情報

  • Google ドライブ（本アプリが作成したファイルのみ）：作品の保存と読み込みに使います。本アプリは、利用者のドライブにある他のファイルを見ることはできません。
  • 共有の設定（家族の美術館を使う場合のみ）：家族の美術館に飾る作品を、リンクを知っている人が見られるように設定します。
  • メールアドレス：どのアカウントに保存しているかを画面に表示するため、および再ログインを簡単にするために、利用者の端末内でのみ使います。

本アプリによる Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。取得した情報を、第三者への提供や広告に使うことはありません。

4. 家族の美術館・見るだけリンク

「家族の美術館」を作る、または参加すると、家族の美術館に飾る作品と、その一覧（公開データ）が「リンクを知っている人は閲覧可」の設定になります。招待リンクや見るだけリンクを受け取った家族・親戚は、ログインなしでこれらを見られます。リンクは推測できない文字列で、検索結果などに表示されることはありません。家族の美術館の作品に書いたコメント（表示名・日時・本文）も、同じく公開データに含まれます。作品ごとに「わたしの部屋だけ」を選んだ作品は共有されません。「共有をやめる」を選ぶと、すべての作品が元の非公開の状態に戻ります。

5. 端末内の保存

表示を速くするため、また電波がないときに撮影した作品を一時的に保管するため、作品のデータを利用者の端末（ブラウザ）内に保存します。メニューの「ログアウト」で端末内のデータは削除されます。

6. データの削除

作品はアプリ内の「しまう（削除）」で削除でき、Google ドライブのゴミ箱に移ります。すべてのデータを削除したい場合は、Google ドライブの「おもいで美術館」フォルダを削除してください。本アプリのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. ご利用にあたっての注意

  • 本アプリは整理収納サービスの無料の特典です。動作やデータの保存を保証するものではなく、ご利用によって生じた損害について、提供者は法令で認められる範囲で責任を負いません。
  • 機能の変更や、サービスの提供終了を予告なく行う場合があります。終了しても、作品の写真は利用者の Google ドライブに残ります。
  • 作品は利用者の Google ドライブに保存され、容量も利用者のアカウントのものを使います。写真に残したあと現物を手放すかどうかは、ご自身で判断してください。
  • 家族の美術館や「見るだけリンク」の作品は、リンクを知っている人なら見られます。ほかの人が写った写真や個人情報の取り扱い、ほかの人の作品を載せるときの了解にご注意ください。
  • 18歳未満の方は、保護者の方の同意を得てご利用ください。保護者が家族の美術館に招待した場合は、招待した保護者が利用に同意したものとします。
